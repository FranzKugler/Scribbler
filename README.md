# Scribbler

A wall-hanging two-belt pen plotter: the bot hangs from two belts running to two anchors on the
wall, two steppers wind them, a servo lifts the pen.

Nothing is built yet. [PLAN.md](PLAN.md) holds the scope, the architecture, the hardware
questions and the phases; [CLAUDE.md](CLAUDE.md) the conventions the code will follow.

The project language is English — code, comments and these documents. The web interface will
speak German and English, following the browser.
